## CARBON execution findings

1. The [published run.sh](https://github.com/Dibae101/ReBL-Plus/blob/8ca9e4787f946d73955a63dc25fba2845396cdbc/run.sh) ignores the supplied report argument and hardcodes the old Memento#169 report path. Do not use the README’s `./run.sh REPORT` command for this collection. The command helper in this folder selects the requested case explicitly.
2. The [published reproduction.py](https://github.com/Dibae101/ReBL-Plus/blob/8ca9e4787f946d73955a63dc25fba2845396cdbc/Automation/reproduction.py) targets `emulator-PORT` and infers the package from the foreground app. Launch and verify the exact package/activity from metadata immediately before starting CARBON. A separate local checkout has an improved runner, but it has uncommitted changes and is not the audited published revision.
3. The repository recommends Android 14, but 25 APKs target an API below 23 and ordinary fresh installation on Android 14 will reject them. [Android documentation](https://developer.android.com/about/versions/14/behavior-changes-all#minimum-target-api-level) documents this restriction and a test-only ADB override. Prefer the reported historical OS when checking reproducibility; bypassing an installation restriction does not restore old runtime behavior.
4. Dagger#46 explicitly needs API 21/22; its report excludes API 23+. Soen#36 contains only x86 native libraries. Other cases need accounts, data files, locale, permissions, network services, SMS/contact state or hardware as listed below.
5. Do not blindly execute upstream_setup.py: some files use fixed screen coordinates, remove files, or choose setup that differs from the original report. For example Aegis#500’s report uses an encrypted vault, while its setup script selects no encryption. Treat these scripts as auxiliary evidence, not authoritative setup.
6. Preserve the frozen bug-report text, APK hash, device/API/ABI, initial state, model configuration, video/logcat and independent symptom oracle for each run. Do not score an install failure, stale service, missing test data or CARBON self-declared success as reproduction evidence.
7. ODK#360’s original Google Drive URL currently returns a virus-scan confirmation HTML page to a simple downloader. Following its confirmation form retrieves the correct 5,207,126-byte APK and matching SHA-256. The packaged APK is valid; restoring it through the existing curl-only downloader may fail. Use the committed APK from the dataset or the verified local archive, not that HTML response.

## Starting a controlled pilot

The first five suggested cases are FastAdapter#394, Screencam#25, Weather#61, AndOPT#135 and Aegis#500. They have short explicit triggers and no unresolved substantive version discrepancy in this review. Prefer the original report’s Android version when stated, otherwise use the benchmark context as a starting point. The benchmark OS column can differ from the reporter’s device; it is not a runtime compatibility certificate. Complete the setup notes before running. These are pilot candidates, not runtime-validated cases.

Use `carbon_case_commands.py --help` to generate explicit commands for one selected emulator/case. It reads and checks local hashes and prints commands only; it does not install, clear data or call an LLM. Example:

```bash
python3 carbon_case_commands.py --dataset /path/to/ReBL-Plus/Dataset/rebl-dataset \
  --carbon /path/to/ReBL-Plus --case "FastAdapter#394" --serial emulator-5554
```

The selected device and CARBON checkout still need to be supplied by the experiment owner. No remote host or emulator was chosen implicitly.
